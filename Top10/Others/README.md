# Others — супернеобычные режимы

Дополнительная коллекция модулей JustMc (Creative+), собранных по навыку JAI v2.1.0. Каждый файл — готовый JSON-модуль: импортируй и пиши команду в чат.

| # | Файл | Режим | Команда | Необычная идея |
|---|------|-------|---------|----------------|
| 1 | FlipWorld | Перевёртыш | \flip / \flip stop | Мир переворачивается каждые 25 сек: все летят с пола на потолок |
| 2 | LavaTrail | Трон-шлейф | \trail | Твой пройденный путь становится лавой (пол сбрасывается каждые 30 сек) |
| 3 | MusicalZone | Музыкальный стул | \chair / \chair stop | Зона безопасности прыгает по арене, кто не добежал — теряет HP, темп растёт |
| 4 | MeteorShower | Метеоритный шторм | \meteor | Метеорит выбирает жертву, огненное кольцо предупреждает точку удара |
| 5 | VolcanoArena | Спящие вулканы | \volcano | Столбы выстреливают из-под ног, жерла на вершинах заливает лавой |
| 6 | HungerDome | Голодная арена | \hunger | Все медленно умирают, спасают только случайные светящиеся оазисы |
| 7 | BlackoutHunt | Чёрная охота | \blackout | Вечная ночь + молния каждые 20 сек выдаёт позицию случайного игрока |
| 8 | PulseArena | Огненное кольцо | \pulse | Ударные волны расходятся из центра радиусами 3-6-9-12-15, ныряй в разрывы |

Все арены строятся автоматически со смещением от спавна (каждый запуск — новая копия). Правила игр задаются сами (PVP только в Чёрной охоте).
