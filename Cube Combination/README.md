# 🟨 Cube Combination (модуль JustMc Creative+)

Ремейк мини-игры **Cube Combination** из Roblox на сервере JustMc (Creative+): парящие острова, генерируемые кодом, спавн кубов, комбинирование кубов в оружие и бесконечные волны врагов с боссами.

## 🎮 Геймплей

- **Острова генерируются кодом**: главный остров 17×17 из травы с земляным основанием + 6 случайных парящих мини-островов (случайные координаты и высота) — генерация выполняется при каждом запуске мира (`CC.genIslands`).
- **Кубы спавнятся сами** каждые 4 секунды на главном острове: 🔴 красный, 🔵 синий, 🟡 жёлтый, 🟢 зелёный (случайный цвет).
- **Комбинирование** (как в оригинале — 2 куба → предмет):

| Кубы | Результат |
|---|---|
| 🔴 + 🔴 | Алмазный меч «Клинок ярости» |
| 🔵 + 🔵 | Лук + 16 стрел |
| 🟡 + 🟡 | 3 золотых яблока |
| 🟢 + 🟢 | Железный нагрудник |

- **Волны врагов**: каждые 15 секунд новая волна (с босс-баром отсчёта), количество и HP «Кубов-врагов» растут с номером волны. Каждая 5-я волна — **БОСС-КУБ** с алмазной бронёй и мечом.
- **Награда за убийство**: случайный куб в инвентарь + очки на скорборде.

## 🕹️ Команды (чат)

| Команда | Описание |
|---|---|
| `@cube` | Начать игру (телепорт на остров, генерация, спавнеры и волны) |
| `@combine` | Скомбинировать 2 одинаковых куба |
| `@cubestop` | Закончить игру (мобы удаляются) |
| `@cc help` | Справка |

Также комбинация доступна **ПКМ по изумрудному блоку** (стол комбинирования) в центре острова.

## 📦 Установка

1. Откройте мир Creative+ на JustMc.
2. Импортируйте модуль из файла `cube_combination.json`.
3. Пиши `@cube` в чат — игра начнётся.

## 🧩 Структура модуля

- `world_start` — инициализация переменных, скорборд, генерация островов
- `player_join` / `player_death` — приветствие и подсказки
- `player_chat` — команды `@cube`, `@combine`, `@cubestop`, `@cc help`
- `player_interact` — ПКМ по изумрудному столу = комбинация
- `player_kill_mob` — награда кубом и очками за убийство
- `CC.genIslands` — процедурная генерация островов
- `CC.combine` — логика комбинирования кубов
- `CC.spawner` — процесс спавна кубов (токен-защита от старых потоков)
- `CC.waves` + `CC.waveIntermission` + `CC.spawnWave` — система волн и боссов
