# NeuroSlop

Коллекция JSON-модулей для мини-игры **Creative+** сервера **JustMc** (система JustMc AI / JAI).
Каждый файл — готовый модуль: импортируйте его в Creative+ на сервере.

## Модули

| Файл | Описание |
|------|-----------|
| `Verity` | Хоррор-боссфайт «Верити — Она Всегда Улыбается» (подробнее ниже) |
| `Cube_Combination` | Мини-игра Cube Combination: генерируемые острова, объединение кубов, волны и боссы, босс-бар HP |
| `Cube Combination/` | Папка с рабочими версиями Cube Combination |
| `Neuro` | Модуль Neuro |
| `Changed_V7` | Changed, версия 7 |
| `Arena_V1` | Шаблон арены (вер. 1) |
| `Break_blocks` | Мини-игра на разрушение блоков |

## 🟡 Verity — Она Всегда Улыбается

Эпичный хоррор-бой с боссом **Верити** (жёлтый смайлик из хоррор-фильма ThatMob): 3 фазы усиления, миньоны, джампскейры, процедурная арена.

### Арена (`VT.build`)
- Строится автоматически при старте мира вокруг точки спавна: чёрный пол 33×33 (`game_clear_region` + `game_set_region`), жёлтый круг-«смайлик» на полу, чёрные глаза и улыбка, стены с glowstone-вставками, 4 колонны из crying obsidian с soul fire на вершинах.

### Босс
- Хаск 300 HP, невидимый и бесшумный, не деспавнится; «лицо» — 4 block-display (жёлтое лицо 2.5×, глаза, рот), следуют за боссом (процесс `VT.face`), жёлтое свечение.
- Бой начинается, когда игрок входит в зону активации у спавна (`if_player_in_area`).

### Фазы (по HP: <200 → 2, <100 → 3)
- **1 фаза** — базовая скорость 0.35, урон 8.
- **2 фаза** — скорость 0.5, урон 12, титул «Верити ускоряется!».
- **3 фаза** — скорость 0.65, урон 16, титул «ЯРОСТЬ ВЕРИТИ», миньоны.

### Атаки (каждые ~2 с, в 3 фазе — ~1 с)
- Взрыв + молния по случайному игроку.
- Рывок босса к случайной цели (`entity_launch_forward`).
- Миньон «Отпрыск Верити» (baby-хаск).

### Хоррор-механики
- Джампскейр + крик гаста — 15% шанс при каждом ударе по боссу.
- Молния в атакера в 3 фазе.
- Босс-бар HP: жёлтый в 1–2 фазах, красный в 3 фазе.
- Победа: удаление миньонов и дисплеев, титул, молния, звук челленджа.

## Правила (JAI v3.0.1)

Модули написаны по правилам скилла **JAI** (JustMc AI) версии 3.0.1:
- Предметы всегда в NBT-формате: `{Count:1b,id:"minecraft:..."}` (в т.ч. слот `block` действий `game_set_block`/`game_set_region`).
- Переменные не требуют нулевой инициализации (значение по умолчанию — 0).
- Лимит строки: ≤33 условий, ≤67 действий (условие = 2 действия).
- Каждый большой цикл (>10 итераций) содержит `control_wait` ≥1 тик; ≤300 итераций без wait за прогон.
- `game_set_region` — до 125 000 блоков за вызов.

Свежая версия скилла: **JAI.zip** — <https://github.com/kitorik/JMCS> (или <https://github.com/kitorik/justmc-ai>).
